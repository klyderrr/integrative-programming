# kly — static mockup

A static HTML/CSS front-end mockup for **kly**, an event management system.

## Pages
- `events.html` — Events
- `venues.html` — Venues
- `attendees.html` — Attendees
- `registrations.html` — Registrations

## Notes
- Pure HTML + CSS, no JavaScript.
- Table rows and data are hardcoded for display only.
- "New / Edit / Delete" buttons are visual only — not functional yet.
- All pages share `style.css`. Keep all files in the same folder.

## Next steps
- Add JS for interactive CRUD (in-browser only), or
- Connect to a real backend + database for persistent data.
